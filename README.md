# Sivilization Shop

A modern e-commerce and entertainment platform built with React, Vite, and Supabase.

## Quick Start

1. Install dependencies: `npm install`
2. Set up .env.local with your Supabase credentials
3. Run: `npm run dev`
4. Open: http://localhost:5173

## Features

- Media streaming (films, cartoons, dramas)
- Games section
- Shop with cart
- Personal library
- User authentication
- Admin panel
